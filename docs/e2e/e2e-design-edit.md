# design-edit E2E 시나리오

## 정상 경로 (Golden Path)

### 기본 정보 수정 후 저장

- **조건**: 로그인 상태, 자신이 소유한 디자인의 수정 페이지에 접근
- **행동**:
  1. 제목 입력 필드를 클리어하고 새 제목을 입력한다
  2. 설명 텍스트 에어리어를 클리어하고 새 설명을 입력한다
  3. 카테고리 버튼 중 하나를 클릭해 카테고리를 변경한다
  4. "Save" 버튼을 클릭한다
- **결과**: 디자인 상세 페이지(`/designs/{designId}`)로 이동하고 변경된 정보가 반영된다

### 썸네일 이미지 교체

- **조건**: 로그인 상태, 기존 썸네일이 있는 디자인의 수정 페이지
- **행동**:
  1. 기존 썸네일의 제거 버튼을 클릭한다
  2. 썸네일 업로드 영역에 새 이미지를 드래그앤드롭 또는 클릭하여 선택한다
  3. 미리보기가 표시되는 것을 확인한다
  4. "Save" 버튼을 클릭한다
- **결과**: 저장 후 상세 페이지에서 새 썸네일이 표시된다

### 갤러리 이미지 일부 추가

- **조건**: 로그인 상태, 기존 갤러리 이미지가 3장인 디자인의 수정 페이지
- **행동**:
  1. 갤러리의 다음 빈 슬롯(+)을 클릭해 이미지 1장을 추가한다
  2. "Save" 버튼을 클릭한다
- **결과**: 기존 3장 + 신규 1장, 총 4장이 유지된다

### 갤러리 이미지 일부 제거

- **조건**: 로그인 상태, 갤러리 이미지가 4장인 디자인의 수정 페이지
- **행동**:
  1. 갤러리 이미지 중 하나의 제거 버튼을 클릭한다
  2. "Save" 버튼을 클릭한다
- **결과**: 제거한 이미지를 제외한 3장만 저장된다

### 설명서 PDF 추가

- **조건**: 로그인 상태, 수정 페이지, 설명서 슬롯에 여유가 있는 상태
- **행동**:
  1. 빈 설명서 슬롯에 PDF 파일을 선택한다
  2. 파일명과 용량이 표시되는 것을 확인한다
  3. "Save" 버튼을 클릭한다
- **결과**: 기존 설명서와 신규 설명서가 함께 저장된다

### 디자인 삭제

- **조건**: 로그인 상태, 자신이 소유한 디자인의 수정 페이지
- **행동**:
  1. "Delete" 버튼을 클릭한다
  2. 확인 다이얼로그에서 확인 버튼을 클릭한다
- **결과**: 홈(`/`)으로 이동하고 해당 디자인이 목록에서 사라진다

## 인증 상태

### 비로그인 상태에서 수정 시도

- **조건**: 비로그인 상태
- **행동**: 디자인 수정 페이지 URL로 직접 접근한다
- **결과**: 로그인 페이지로 리다이렉트되거나 접근이 차단된다

### 타인의 디자인 수정 시도

- **조건**: 로그인 상태, 다른 사용자가 소유한 디자인의 수정 페이지 URL 직접 접근
- **행동**: "Save" 버튼을 클릭한다
- **결과**: "수정 권한이 없습니다." 에러가 표시되고 저장되지 않는다

### 타인의 디자인 삭제 시도

- **조건**: 로그인 상태, 다른 사용자가 소유한 디자인의 수정 페이지 URL 직접 접근
- **행동**: "Delete" 버튼을 클릭하고 확인한다
- **결과**: "수정 권한이 없습니다." 에러가 표시되고 삭제되지 않는다

## 유효성 오류

### 제목 미입력

- **조건**: 로그인 상태, 디자인 수정 페이지
- **행동**: 제목 필드를 비우고 "Save" 버튼을 클릭한다
- **결과**: 제목 필드에 에러 메시지가 표시되고 저장되지 않는다

### 제목 최대 길이 초과 (120자 초과)

- **조건**: 로그인 상태, 디자인 수정 페이지
- **행동**: 제목 필드에 121자 이상의 텍스트를 입력하고 "Save" 버튼을 클릭한다
- **결과**: 제목 필드에 에러 메시지가 표시되고 저장되지 않는다

### 설명 미입력

- **조건**: 로그인 상태, 디자인 수정 페이지
- **행동**: 설명 필드를 비우고 "Save" 버튼을 클릭한다
- **결과**: 설명 필드에 에러 메시지가 표시되고 저장되지 않는다

### PDF가 아닌 파일 업로드 시도

- **조건**: 로그인 상태, 디자인 수정 페이지
- **행동**: 설명서 슬롯에 PDF가 아닌 파일(예: 이미지)을 업로드하려 한다
- **결과**: 파일 선택이 거부되거나 에러 메시지가 표시된다

### 이미지 슬롯 최대치(6장) 초과 시도

- **조건**: 로그인 상태, 갤러리 이미지가 이미 6장인 디자인의 수정 페이지
- **행동**: 추가 이미지를 업로드하려 한다
- **결과**: 추가 슬롯이 표시되지 않아 더 이상 업로드할 수 없다

### 이미지 파일 크기 초과 (10MB 초과)

- **조건**: 로그인 상태, 디자인 수정 페이지
- **행동**: 10MB를 초과하는 이미지 파일을 썸네일 또는 갤러리에 업로드하려 한다
- **결과**: 에러 메시지가 표시되고 파일이 추가되지 않는다

## 경계 케이스

### 갤러리 이미지가 정확히 6장일 때

- **조건**: 로그인 상태, 갤러리 이미지 6장인 디자인의 수정 페이지
- **행동**: 수정 페이지를 열어 갤러리 상태를 확인한다
- **결과**: 갤러리 그리드에 추가(+) 슬롯이 표시되지 않는다

### 설명서가 정확히 2개일 때

- **조건**: 로그인 상태, 설명서 2개가 첨부된 디자인의 수정 페이지
- **행동**: 수정 페이지를 열어 설명서 영역 상태를 확인한다
- **결과**: 설명서 추가 슬롯이 더 이상 표시되지 않는다

### 설명 최대 길이 경계 (2000자)

- **조건**: 로그인 상태, 디자인 수정 페이지
- **행동**: 설명 필드에 정확히 2000자를 입력하고 "Save" 버튼을 클릭한다
- **결과**: 에러 없이 저장된다

### 기존 파일 유지 + 신규 파일 혼합 저장

- **조건**: 로그인 상태, 기존 갤러리 이미지와 설명서가 있는 디자인의 수정 페이지
- **행동**:
  1. 기존 갤러리 이미지 중 1장을 제거한다
  2. 새 이미지 1장을 추가한다
  3. "Save" 버튼을 클릭한다
- **결과**: 제거한 이미지는 없어지고, 유지된 기존 이미지 + 신규 이미지로 저장된다

## 서버·네트워크 오류

### 파일 업로드 실패 시 롤백

- **조건**: 로그인 상태, 디자인 수정 페이지, 업로드 중 네트워크 오류 발생 시뮬레이션
- **행동**:
  1. 새 이미지를 갤러리에 추가한다
  2. "Save" 버튼을 클릭한다 (업로드 중 네트워크 오류 발생)
- **결과**: 에러 메시지가 표시되고, 기존 디자인 상태는 변경되지 않는다

### DB 저장 실패 시 에러 표시

- **조건**: 로그인 상태, 디자인 수정 페이지, 서버 액션 실패 시뮬레이션
- **행동**: 폼을 정상적으로 작성하고 "Save" 버튼을 클릭한다 (서버에서 오류 반환)
- **결과**: 폼 상단 또는 해당 위치에 에러 메시지가 표시되고 페이지 이동이 없다

### 삭제 실패 시 에러 표시

- **조건**: 로그인 상태, 디자인 수정 페이지, 삭제 서버 액션 실패 시뮬레이션
- **행동**: "Delete" 버튼을 클릭하고 확인한다 (서버에서 오류 반환)
- **결과**: 에러 메시지가 표시되고 홈으로 이동하지 않으며 디자인은 유지된다
