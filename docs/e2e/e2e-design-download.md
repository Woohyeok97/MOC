# E2E 시나리오: 설명서 다운로드 (design-download)

## 정상 경로

### 소유자가 설명서를 다운로드한다

- **조건**: 로그인한 사용자가 자신이 등록한 디자인 상세 페이지에 있고, 설명서 파일이 1개 이상 존재한다
- **행동**: 설명서 항목의 다운로드 버튼을 클릭한다
- **결과**: 새 탭이 열리며 서명된 URL을 통해 파일 다운로드가 시작된다

### 다른 사용자(viewer)가 설명서를 다운로드한다

- **조건**: 로그인한 사용자가 타인의 디자인 상세 페이지에 있고, 설명서 파일이 1개 이상 존재한다
- **행동**: 설명서 항목의 다운로드 버튼을 클릭한다
- **결과**: 새 탭이 열리며 서명된 URL을 통해 파일 다운로드가 시작된다

### 여러 설명서 파일을 각각 다운로드한다

- **조건**: 로그인한 사용자가 설명서 파일이 여러 개인 디자인 상세 페이지에 있다
- **행동**:
  1. 첫 번째 설명서 항목의 다운로드 버튼을 클릭한다
  2. 두 번째 설명서 항목의 다운로드 버튼을 클릭한다
- **결과**: 각각 별도의 새 탭이 열리며, 각 파일에 맞는 원본 파일명으로 다운로드가 시작된다

## 인증 상태

### 비로그인 사용자는 다운로드 버튼이 잠금 상태로 표시된다

- **조건**: 로그인하지 않은 사용자가 설명서가 있는 디자인 상세 페이지에 접근한다
- **행동**: 설명서 목록을 확인한다
- **결과**: 모든 설명서 항목의 버튼에 자물쇠 아이콘이 표시되고, 버튼이 비활성화되어 있다

### 비로그인 사용자가 잠긴 버튼을 클릭해도 반응이 없다

- **조건**: 로그인하지 않은 사용자가 설명서가 있는 디자인 상세 페이지에 있다
- **행동**: 자물쇠 아이콘이 표시된 버튼을 클릭한다
- **결과**: 아무 동작도 발생하지 않으며, 새 탭이 열리지 않는다

## 경계 케이스

### 다운로드 요청 중에는 버튼이 비활성화된다

- **조건**: 로그인한 사용자가 설명서 다운로드 버튼을 클릭해 요청이 진행 중이다
- **행동**: 응답이 오기 전에 동일한 버튼을 다시 클릭한다
- **결과**: 버튼이 비활성화 상태로 유지되어 중복 요청이 발생하지 않는다

## 서버·네트워크 오류

### 서버에서 서명 URL 생성에 실패하면 오류가 처리된다

- **조건**: 로그인한 사용자가 설명서 다운로드 버튼을 클릭했으나 서버에서 URL 생성에 실패한다
- **행동**: 다운로드 버튼을 클릭한다
- **결과**: 새 탭이 열리지 않으며, 다운로드가 실패했음을 알 수 있는 상태가 된다 (버튼이 다시 활성화됨)
