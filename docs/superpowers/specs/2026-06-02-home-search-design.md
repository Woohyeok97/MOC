# 메인 홈 검색 기능 설계

작성일: 2026-06-02
상태: 설계 확정 (구현 대기)

## 1. 배경 / 문제

메인 홈(`/`)의 검색은 현재 "가짜 검색"이다.

- `getDesigns()`가 **모든 디자인을 통째로** DB에서 가져온다.
- `page.tsx`(서버 컴포넌트)가 받아온 전체 목록을 `title` / `author.name` 기준으로
  `includes()` **클라이언트 필터링**한다.

데이터가 늘어날수록 매 요청마다 전체 행을 메모리에 올려 필터링하므로 비효율적이고,
"실제 웹서비스 검색" 답지 않다. 데이터 요청 방식을 **진짜 서버사이드 검색**으로 바꾼다.

## 2. 범위 (브레인스토밍 확정)

**포함:**

- 서버사이드 제목(title) 검색 — DB `WHERE`에서 직접 필터
- 검색 결과는 **별도 페이지 없이 현재 홈(`/`)에서** 표시 (핀터레스트식)
- 검색 실행 시점은 **엔터 키(폼 submit)**

**제외 (추후 과제):**

- 페이지네이션 / 무한 스크롤 (cursor 기반 데이터 요청)
- 카테고리 필터 / 정렬 옵션
- 자동완성 · 검색어 추천 · 최근 검색어
- 제목 외 필드(설명, 작성자명, 카테고리) 검색
  - 주의: 기존 클라 필터의 `author.name` 매칭은 이번 변경으로 **제거**된다.

YAGNI 원칙에 따라 위 제외 항목은 의도적으로 넣지 않는다.

## 3. 설계

### 3.1 데이터 흐름

```
Header(client)  --엔터-->  URL ?query=...  -->  Home page.tsx(server)
                                                     |
                                                     v
                                         getDesigns(query)  -->  Prisma
                                                                  WHERE title ILIKE
```

- 검색 상태의 단일 출처는 **URL query 파라미터** (`?query=`).
- 서버 컴포넌트가 query를 읽어 `getDesigns(query)`로 데이터를 요청한다.
- 클라이언트는 필터링을 하지 않는다.

### 3.2 컴포넌트별 변경

#### A. `src/entities/design/design.api.ts` — `getDesigns`

- 시그니처: `getDesigns(query?: string)`.
- `query`가 truthy면 Prisma `where`에 제목 부분일치(대소문자 무시):
  ```ts
  where: query ? { title: { contains: query, mode: 'insensitive' } } : undefined;
  ```
- `orderBy: { createdAt: 'desc' }`, `include: { author: true }`, thumbnail 공개 URL 변환은 그대로 유지.
- `React.cache`는 인자별 메모이즈를 지원하므로 `cache(...)` 래핑 유지.

#### B. `src/app/(main)/(with-sidebar)/page.tsx`

- `await searchParams`에서 `query` 추출 유지.
- 클라이언트 `filteredDesigns = designs.filter(...)` 블록 **삭제**.
- `const designs = await getDesigns(query);` 호출 후 그대로 렌더.
- 빈 상태(`length === 0`) "검색 결과가 없어요" 메시지 UI는 유지.

#### C. `src/widgets/Header.tsx`

- 검색창 `<input>`을 `<form>`으로 감싸 `onSubmit`에서 검색 실행(엔터 자연 처리).
- `onChange`는 로컬 `searchValue` state만 갱신 (즉시 `router.replace` 제거).
- submit 시 기존 로직대로: 값이 있으면 `params.set('query', value)`, 비어 있으면
  `params.delete('query')` 후 `router.replace('/?' + params)`.
- 기존 검색창 외형(`focus-within` 스타일 등)은 `<form>`으로 이동시켜 동일하게 유지.

## 4. 엣지 케이스 / 에러 처리

- 빈 검색어 엔터 → `query` 파라미터 제거 → 전체 목록 표시.
- 매칭 결과 0건 → 기존 "검색 결과가 없어요" 메시지 표시.
- 대소문자 차이 → `mode: 'insensitive'`로 동일 취급.
- 앞뒤 공백: 별도 trim은 이번 범위에서 다루지 않음(필요 시 추후). `contains`가 공백 포함 그대로 매칭.

## 5. 검증 방법

1. `yarn dev` 실행.
2. 존재하는 제목 일부 입력 후 엔터 → URL `/?query=...` 반영 + 제목 매칭 결과만 표시.
3. 대소문자 다르게 입력 → 동일 결과.
4. 검색창 비우고 엔터 → 전체 목록 복귀.
5. 매칭 없는 검색어 → "검색 결과가 없어요" 표시.
6. (선택) Prisma 쿼리 로그로 `WHERE title ILIKE` 발생 확인 (전체 select 아님).
7. (선택) Playwright E2E 검색 시나리오 추가 (아래 6장 기준).

## 6. E2E 시나리오

구현 완료 후 Playwright 테스트 코드 작성의 기준이 되는 자연어 시나리오. 셀렉터는 포함하지 않는다.

### 정상 경로

#### 제목 검색으로 결과 좁히기

- **조건**: 홈(`/`)에 서로 다른 제목의 디자인이 여러 개 표시된 상태.
- **행동**:
  1. 검색창에 특정 디자인 제목의 일부를 입력한다.
  2. 엔터를 누른다.
- **결과**: URL이 `/?query=<입력값>`으로 바뀌고, 제목에 해당 문자열을 포함한 디자인만 목록에 남는다. 포함하지 않는 디자인은 사라진다.

#### 대소문자 구분 없이 검색

- **조건**: 제목이 "콜라를 레고로 만들면?"인 디자인이 존재.
- **행동**: 검색창에 "콜라"을 입력하고 엔터.
- **결과**: 대소문자와 무관하게 "콜라를 레고로 만들면?" 디자인이 결과에 포함된다.

### 검색 실행 시점

#### 타이핑 중에는 검색이 실행되지 않음

- **조건**: 홈에 전체 디자인이 표시된 상태.
- **행동**: 검색창에 글자를 입력하되 엔터를 누르지 않는다.
- **결과**: URL의 `query` 파라미터와 표시 목록이 바뀌지 않는다. 엔터를 누른 시점에만 결과가 갱신된다.

### 경계 케이스

#### 검색어를 비우면 전체 목록으로 복귀

- **조건**: 검색이 적용되어 일부 디자인만 보이는 상태(`/?query=...`).
- **행동**: 검색창을 모두 지우고 엔터.
- **결과**: URL에서 `query` 파라미터가 제거되고 전체 디자인 목록이 다시 표시된다.

#### 매칭 결과가 없을 때 빈 상태 안내

- **조건**: 어떤 디자인 제목과도 매칭되지 않는 검색어.
- **행동**: 해당 검색어를 입력하고 엔터.
- **결과**: 카드가 하나도 표시되지 않고 "검색 결과가 없어요" 메시지가 나타난다.

#### 디자인이 하나도 없는 빈 DB

- **조건**: 등록된 디자인이 0건인 상태로 홈에 진입.
- **행동**: 별도 행동 없이 페이지를 본다.
- **결과**: 카드가 없고 "검색 결과가 없어요" 메시지가 표시된다.

### 상태 동기화 (URL 직접 진입)

#### 쿼리 파라미터가 포함된 URL로 직접 진입

- **조건**: 제목에 "나무"을 포함하는 디자인이 존재.
- **행동**: 주소창에 `/?query=나무`을 직접 입력해 진입한다.
- **결과**: 진입 즉시 "나무"을 포함한 디자인만 표시되고, 검색창 입력값에도 "나무"이 채워져 있다.

### 인증 상태

#### 비로그인 사용자도 검색 가능

- **조건**: 로그아웃 상태로 홈에 진입.
- **행동**: 검색창에 제목 일부를 입력하고 엔터.
- **결과**: 로그인 여부와 무관하게 검색이 정상 동작하고 결과가 필터링된다. (검색은 인증 분기가 없다.)
