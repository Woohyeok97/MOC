# 디자인 생성 E2E 시나리오

기능: `src/features/design-create/`

---

## 정상 경로

### 무료 디자인 등록 성공

- **조건**: 로그인 상태, 디자인 생성 페이지 진입
- **행동**:
  1. 제목, 설명, 카테고리 입력
  2. 썸네일 이미지 첨부
  3. "Free" 체크박스 체크
  4. "Publish" 버튼 클릭
- **결과**: 버튼이 "Publishing..."으로 변경되며 비활성화 → 등록 완료 후 생성된 디자인 상세 페이지로 이동

### 유료 디자인 등록 성공

- **조건**: 로그인 상태, 디자인 생성 페이지 진입
- **행동**:
  1. 제목, 설명, 카테고리 입력
  2. 썸네일 이미지 첨부
  3. 가격 입력 (예: 5000)
  4. 설명서 PDF 1개 이상 첨부
  5. "Publish" 버튼 클릭
- **결과**: 등록 완료 후 생성된 디자인 상세 페이지로 이동

### 갤러리 이미지 포함 등록 성공

- **조건**: 로그인 상태, 디자인 생성 페이지 진입
- **행동**:
  1. 필수 필드 모두 입력
  2. 갤러리 이미지 6장 첨부
  3. "Publish" 버튼 클릭
- **결과**: 등록 완료 후 상세 페이지로 이동, 갤러리 카운트가 "Gallery (6/6)"으로 표시됨

---

## 인증 상태

### 비로그인 상태에서 폼 제출

- **조건**: 비로그인 상태로 디자인 생성 페이지 진입 (또는 로그인 만료 상태)
- **행동**:
  1. 모든 필드를 정상적으로 입력
  2. "Publish" 버튼 클릭
- **결과**: 폼 제출 에러 메시지 ("로그인이 필요합니다.") 표시, 페이지 이동 없음

---

## 유효성 오류

### 필수 필드 전체 미입력 상태에서 제출

- **조건**: 로그인 상태, 아무 필드도 입력하지 않음
- **행동**: "Publish" 버튼 클릭
- **결과**: 제목, 설명, 카테고리, 썸네일 각 필드에 에러 메시지 표시, 페이지 이동 없음

### 제목 최대 길이 초과

- **조건**: 로그인 상태, 제목 입력란에 121자 이상 입력
- **행동**: 나머지 필드 정상 입력 후 "Publish" 버튼 클릭
- **결과**: 제목 필드에 "Max 120 characters." 에러 메시지 표시

### 설명 최대 길이 초과

- **조건**: 로그인 상태, 설명 입력란에 2001자 이상 입력
- **행동**: 나머지 필드 정상 입력 후 "Publish" 버튼 클릭
- **결과**: 설명 필드에 "Max 2000 characters." 에러 메시지 표시

### 카테고리 미선택

- **조건**: 로그인 상태, 카테고리를 선택하지 않음
- **행동**: 제목, 설명 입력 후 "Publish" 버튼 클릭
- **결과**: 카테고리 필드에 "Please select a category." 에러 메시지 표시

### 썸네일 미첨부

- **조건**: 로그인 상태, 썸네일을 첨부하지 않음
- **행동**: 나머지 필드 정상 입력 후 "Publish" 버튼 클릭
- **결과**: 썸네일 필드에 "Thumbnail is required." 에러 메시지 표시

### 썸네일에 이미지가 아닌 파일 첨부

- **조건**: 로그인 상태
- **행동**: 썸네일 업로드 영역에 PDF 또는 텍스트 파일 선택
- **결과**: 썸네일 필드에 "Only image files are allowed." 에러 메시지 표시

### 썸네일 파일 크기 초과

- **조건**: 로그인 상태
- **행동**: 썸네일 업로드 영역에 10MB 초과 이미지 선택
- **결과**: 썸네일 필드에 "Max file size is 10MB." 에러 메시지 표시

### 갤러리 이미지에 이미지가 아닌 파일 첨부

- **조건**: 로그인 상태
- **행동**: 갤러리 이미지 업로드 영역에 PDF 파일 선택
- **결과**: 해당 갤러리 이미지 슬롯에 "Only image files are allowed." 에러 메시지 표시

### 유료 디자인인데 가격 미입력

- **조건**: 로그인 상태, "Free" 체크박스 미체크 상태 (기본값)
- **행동**: 나머지 필드 정상 입력, 가격 필드는 0 또는 빈 값으로 두고 PDF 첨부 후 "Publish" 버튼 클릭
- **결과**: 가격 필드에 "Please set a price for paid designs." 에러 메시지 표시

### 유료 디자인인데 설명서 PDF 미첨부

- **조건**: 로그인 상태, "Free" 체크박스 미체크 상태
- **행동**: 나머지 필드 정상 입력, 가격 입력, 설명서 PDF 미첨부 후 "Publish" 버튼 클릭
- **결과**: 설명서 필드에 "Please upload at least one instruction PDF for paid designs." 에러 메시지 표시

### 설명서에 PDF가 아닌 파일 첨부

- **조건**: 로그인 상태
- **행동**: 설명서 업로드 슬롯에서 이미지 파일 선택
- **결과**: 설명서 필드에 "Only PDF files are allowed." 에러 메시지 표시

## 경계 케이스

### 갤러리 이미지 최대 6개 제한

- **조건**: 로그인 상태, 갤러리 이미지 슬롯에 이미 6장이 추가된 상태
- **행동**: 갤러리 이미지 카운트 레이블 확인
- **결과**: 레이블이 "Gallery (6/6)"으로 표시되고, 추가 업로드 슬롯이 보이지 않음

### 설명서 PDF 최대 2개 제한

- **조건**: 로그인 상태, 설명서 PDF를 1개 첨부한 상태
- **행동**: 두 번째 PDF 첨부 후 업로드 슬롯 상태 확인
- **결과**: 두 번째 파일 첨부 후 추가 업로드 버튼이 사라지고 총 2개 슬롯만 표시

### Free 체크박스 토글 시 가격 필드 초기화

- **조건**: 로그인 상태, 유료 모드에서 가격 5000 입력 후 제출 시도로 유효성 오류 발생한 상태
- **행동**: "Free" 체크박스 체크
- **결과**: 가격 입력 필드가 비활성화되고 placeholder "Free" 표시, 가격 에러 메시지 사라짐

### Free → 유료 전환 후 재검증

- **조건**: 로그인 상태, "Free" 체크 상태에서 제출 후 "Free" 체크 해제
- **행동**: 가격 0 유지, PDF 미첨부 상태에서 "Publish" 버튼 클릭
- **결과**: 가격 에러 메시지와 설명서 에러 메시지가 모두 표시됨

## 서버 · 네트워크 오류

### 파일 업로드 실패

- **조건**: 로그인 상태, 모든 필드 정상 입력
- **행동**: 네트워크 차단 또는 스토리지 오류 상황에서 "Publish" 버튼 클릭
- **결과**: 폼 하단에 에러 메시지 표시, 페이지 이동 없음, 이미 업로드된 파일은 롤백됨

### DB 저장 실패

- **조건**: 로그인 상태, 파일 업로드는 성공하나 서버 액션 오류 발생
- **행동**: "Publish" 버튼 클릭
- **결과**: 폼 하단에 에러 메시지 표시, 업로드된 파일 폴더 롤백, 페이지 이동 없음
