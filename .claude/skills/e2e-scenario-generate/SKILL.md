# E2E 시나리오 생성

## 개요

스펙 문서 또는 기존 코드를 분석해서 자연어 E2E 테스트 시나리오를 작성한다.
작성된 시나리오는 구현 완료 후 Playwright 테스트 코드 작성의 기준이 된다.

## 동작 모드

### 스펙 모드 (신규 기능)

`/e2e-scenario-generate [spec-file-path]` 으로 호출 시, 지정한 스펙 문서를 읽어 시나리오 생성.

### 코드 모드 (기존 기능)

`/e2e-scenario-generate [feature-name]` 으로 호출 시, 해당 feature 디렉토리 코드를 탐색해서 시나리오 생성.

## 시나리오 커버리지 기준

각 기능에서 반드시 포함:

- 정상 경로 (golden path)
- 인증 상태 (로그인/비로그인 분기가 있는 경우)
- 에러 상태 (유효성 오류, 서버 실패 등)
- 경계 케이스 (빈 목록, 최대치 등 해당하는 경우)

## 출력 형식

```markdown
## [섹션명] (정상 경로 / 인증 상태 / 유효성 오류 / 경계 케이스 / 서버·네트워크 오류)

### [시나리오명]

- **조건**: [초기 상태]
- **행동**:
  1. [첫 번째 단계]
  2. [두 번째 단계]
- **결과**: [예상 결과]
```

- 행동이 단일 동작이면 번호 리스트 대신 한 줄로 작성
- 코드나 셀렉터는 포함하지 않는다. 자연어로만 작성한다.

## 저장 위치

- 스펙 모드: 해당 스펙 문서에 `## E2E 시나리오` 섹션을 추가
- 코드 모드: `docs/e2e/[feature-name].md` 파일 생성
